# Poke 🎯

Poke is a personal accountability system designed to help you stay on track with your goals. You setup recurring goals on the platform and get reminded about them via text message. For example, if you want to go to the gym three days a week, you can add a reminder in Poke to message you on your gym days. Poke will keep track of when you accomplish your goals or when you've slipped up.

## Features

Stay accountable with automated SMS reminders and progress tracking.

## MVP

- User can create reminders that will be regularly sent as text
- User can set which days reminders are sent
- User can set which times reminders are sent
- User can respond to text to confirm completion
- User can response to text to disable reminders (”snooze”)
- User gets reminded if they do not respond to text
- User can manage their reminders

## Stretch Goals

- User can see dashboard summarizing their reminders
- User can see data visualization of their streaks
- Integration with calendar apps
- Support for team accountability groups
- Customizable reminder messages

## Tech Stack

- Backend API for handling reminders and user data
- SMS integration for text message delivery
- Database for storing user goals and progress
